## 1. 選題方法論

### 選題交集模型

一個好選題 = 你的專業領域 + 讀者的普遍興趣 + 當下的時間節點

光是專業，可能曲高和寡。光是讀者興趣，可能流於膚淺。光是蹭熱點，可能曇花一現。三者結合才能找到最精準的引爆點。

### 選題來源

**X（Twitter）**：每日搜尋"AI"關鍵詞，抓一手資訊，關注AI博主和公司動態
**Reddit**：r/artificial、r/ChatGPT、r/singularity、r/ClaudeAI等（100+upvote算比較火）
**小紅書**：大眾輿論場裡AI的話題焦點，重點關注評論區
**即刻**：AI博主、產品創意、行業洞察
**微博/抖音/B站**：熱搜話題，至少兩三個平臺同時火才算真正"破圈"
**讀者社群**：群友的難點、痛點、經常出現的需求，監測"有沒有"、"推薦"等關鍵詞

### HKR質檢法

動筆前每個選題必須通過：
- **H (Happy)** 足夠有趣、有懸念？標題和開頭能讓人好奇想點開？
- **K (Knowledge)** 有資訊量？看完能學到新東西？
- **R (Resonance)** 能戳中情緒？讓人"對對對我也這麼想"？

S級選題三項兼備，及格至少兩項，只佔一項要重新審視，零項堅決放棄。

### 角色代入法（發散思考）

審視選題時代入不同角色：
- "一個很忙的普通使用者"：能幫我省時間/解決具體麻煩嗎？
- "一個愛玩的朋友"：夠有趣嗎？能讓我產生"臥槽還能這樣？"的驚歎？
- "一個焦慮的學習者"：能讓我學到新東西、有新角度嗎？

## 2. 選題分類與過往爆款案例

### 按業務類型

**大模型技術**（大模型、演算法、Agent、程式設計）
- GPT-5.2釋出，真正的牛馬打工人專屬AI來了。
- 用豆包手機的這兩週，我好像捲入了一場新與舊的戰爭。
- 親手給AI投毒之後，我覺得整個網際網路都變成了一座黑暗森林。
- RPA+AI，才是真正能讓你躺平的自動化真神。
- 我用AI監控了奧特曼，當他一發推特AI就會自動給我打電話。

**AIGC藝術**（AI設計、影片、音樂、數字人、玩法創意）
- 火爆全網的AI片場探班玩法，手把手教會你。
- Suno V5讓整個B站開始文藝復興了。
- 周杰倫發的1400萬人點讚的AI影片，是怎麼做出來的？
- Nano Banana一戰封神，我總結了10種官方不會告訴你的神級技巧。

**泛網際網路文化**（深度訪談、現象故事、觀點解讀、政策解讀）
- 淘寶上賣9塊9的DeepSeek，讓我看到了被摺疊的魔幻世界。
- 分析了1.8億個崗位後，我發現應屆生們好像被AI堵在了門外。
- 假扮AI的17歲男高中生，用回覆治癒了整個B站。
- 全世界的賽博難民，正在瘋狂湧進小紅書。

### 按內容類型

**產品評測+推薦**：實測體驗為主，有明確好惡判斷
**玩法+教程分享**：手把手教讀者操作，核心是Prompt和步驟
**現象訪談類**：網際網路現象解讀、人物專訪故事
**認知觀點**：對事件的深度分析、論文分享
**AI整活**：自己動手做好玩的東西，展示AI的可能性

### 按寫作原型（從8篇最佳文章中提煉）

**調查實驗型**
親自下場做一件事，邊做邊報道發現。最能建立信任感和敘事張力。
- 淘寶上賣9塊9的DeepSeek → 買了，看到發過來的居然是免費網址
- 親手給AI投毒 → 註冊小號、發假筆記、一步步看AI被汙染
- 我花499找人上門安裝OpenClaw → 派人實際體驗上門服務
寫法核心：過程敘事 + 層層發現 + 每一步都帶真實反應

**產品體驗型**
拿到產品實際使用，帶著讀者一起體驗。不是評測報告，是"跟我一起玩"。
- miclaw手機Agent → 從設定人設開始，逐個演示功能
- Seedance 2.0 → 按玩法分類，每個玩法配真實case
寫法核心：場景驅動 + 自己的真實感受 + 跟其他產品的自然對比

**現象解讀型**
觀察到一個有趣的現象，然後層層深入分析。
- 三宮格圖片刷屏 → 追問為什麼這麼火 → 連結到十年前的黑邊照片 → 人生敘事需求
- AI看不到愛心 → 逐個模型測試 → 找到論文 → 時間盲視 → 格式塔心理學 → 哲學感悟
寫法核心：好奇心驅動 → 研究 → 知識掉落 → 哲學升維

**工具分享型**
分享一個實用的工具/Prompt，但必須用個人故事包裹，不能直接"推薦一個好用的xxx"。
- 天賦挖掘Prompt → 從朋友的焦慮聊起 → 天賦這個詞的思考 → 工具展示 → 自己的測試結果
寫法核心：個人故事鋪墊 → 自然引出工具 → 自己的使用過程 → 效果展示

## 3. 內容節奏

節奏不是文筆問題，是一套讓讀者一路往下讀的推進系統。

好的節奏像波動：每次圍繞主線偏出去一點點（讓讀者喘口氣、長見識、看案例），再用一句話拉回來繼續推進。

**扣主線句**要高頻出現——不需要長，一句就夠，但頻率要高。

**最忌諱**：突然偏離主線很遠再硬拽回來，讀者要花腦力"順邏輯"，心流斷掉。

節奏優先順序：專業（底子）→ 觀點（方向）→ 主線（繩子）→ 節奏（牽引力）

**對標參考**：影視颶風、何同學、小獅日記、畢導、小Lin、九邊

## 4. 創意案例工作法

### 三類錨點

**熱點錨點**：當下最火的電影、電視劇、社會事件、網路熱梗——流量最大公約數
**痛點錨點**：使用者最高頻、最頭疼的問題——實用價值
**炫技點錨點**：AI工具本身最顛覆的核心功能——技術驚歎

### 包裝成微型故事

1. 亮出"挑戰"：想解決什麼問題？
2. 展示"腦洞"：想到了什麼騷操作？
3. 秀出"過程"：怎麼一步步實現的？（截圖、核心Prompt）
4. 引爆"結果"：最終那個讓人"臥槽"的作品

**準則**：案例必須有獨立的觀賞價值、創意價值和啟發價值。如果自己都High不起來，堅決不發。
