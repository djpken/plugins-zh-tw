# Engineering

日常程式碼工作用的 skills。

## User-invoked

只有輸入時才會觸發(`disable-model-invocation: true`)。

- **[git-fork-remotes](./git-fork-remotes/SKILL.md)** — Fork 一個 repo 之後,設定好 fork/upstream remote,並修正 branch tracking。
- **[writing-router-skill](./writing-router-skill/SKILL.md)** — 詢問這個 repo 裡哪個 skill 適合你目前的情況,整個 skill 集合的路由器。

## Model-invoked

可由使用者觸發,也可由 model 觸發(有豐富的觸發語句讓 model 可以自動找到它們)。

- **[neat-freak](./neat-freak/SKILL.md)** — 知識與治理收尾:讓專案文件、rule 檔案、經授權的 agent memory、workspace 殘留物,對齊程式碼與 runtime 實際的現況。
